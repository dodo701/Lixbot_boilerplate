# LIX Discord Bot

## 📌 요구 사항
* Python 3.8 이상
* `discord.py` (디스코드 봇 프레임워크)
* `python-dotenv` (환경변수 관리)
* `aiohttp` (비동기 API 요청 및 이미지 다운로드)

### 패키지 설치
터미널에서 아래 명령어를 실행하여 필수 패키지들을 설치합니다.
```bash
pip install discord.py python-dotenv aiohttp
```

   ```env
   DISCORD_TOKEN=여기에_발급받은_디스코드_봇_토큰_입력
   LIX_BOT_TOKEN=lixbot_5MV9xsUIpsmJ6W39KQiZah8dGVgwgcrSZpppIBz7-84
   ```
2. 터미널을 열고 메인 봇 파일을 실행합니다.
   ```bash
   python discord_test_bot.py
   ```
3. 봇이 온라인 상태가 되면, 디스코드 채팅창에서 `/글확인` 혹은 `/정보` 슬래시 명령어를 테스트할 수 있습니다.

### 1. 최상위 구조

전체 데이터는 크게 게시글 목록을 담은 `data`와 봇의 정보를 담은 **`bot`** 두 가지로 나뉘어 있습니다.

* **`data`**: 여러 개의 게시글 객체(Object)들이 담겨 있는 배열(Array)입니다.
* **`bot`**: 이 데이터를 호출했거나 연동된 봇의 정보를 나타냅니다.

---

### 2. `data` (게시글 요소 상세)

`data` 배열 안에는 각각의 게시글 정보가 담겨 있으며, 공통적으로 다음과 같은 속성들을 가집니다.

* **`id`** (`String`): 게시글의 고유 식별자입니다. 중복되지 않는 UUID(범용 고유 식별자) 형식으로 되어 있어 DB에서 특정 글을 찾을 때 사용됩니다.
* **`title`** (`String`): 게시글의 제목입니다.
* **`content`** (`String`): 게시글의 본문 내용입니다. (줄바꿈 `\n` 이나 HTML 태그 등이 그대로 포함되어 있습니다.)
* **`region`** (`String`): 글이 작성된 지역 카테고리입니다. (예: "전체", "부산", "경북", "서울")
* **`board`** (`String`): 글이 작성된 게시판의 종류입니다. (예: "자유")
* **`author`** (`String`): 작성자의 닉네임입니다.
* **`anonymous`** (`Boolean`): 익명 여부입니다.
* `true`: 익명글 (화면에는 '익명'으로 표시됨)
* `false`: 기명글 (화면에는 `author`의 닉네임이 표시됨)


* **`likes`** (`Integer`): 게시글이 받은 '좋아요' 개수입니다.
* **`views`** (`Integer`): 게시글의 '조회수'입니다. (데이터를 보니 새로고침 시 조회수가 무한으로 올라가는 버그를 누군가 제보해 두었네요.)
* **`createdAt`** (`String`): 게시글이 작성된 날짜와 시간입니다. ISO 8601 국제 표준 형식(예: `2026-09-25T05:06:09.145Z`)을 따르고 있으며, 끝의 'Z'는 UTC(협정 세계시) 기준임을 의미합니다. 한국 시간으로 보여주려면 +9시간을 더해야 합니다.

**[특정 글에만 있는 선택적 요소]**

* **`communityId`** (`String`): 모든 글에 있지는 않으며, 특정 소규모 커뮤니티나 그룹 게시판에 작성된 글일 경우 해당 커뮤니티의 고유 ID가 부여됩니다.
* **`imageUrl`** (`String`): 작성자가 이미지를 첨부했을 때 생성되는 이미지의 저장 경로(URL)입니다.

---

### 3. `bot` (봇 정보)

맨 마지막에 포함된 봇 객체의 정보입니다.

* **`id`**: 봇에 부여된 고유 식별값입니다. (`6379545c026a7d65`)
* **`name`**: 봇의 이름입니다. (`testbot`)

---

### 4. `bot_info` API 반환 데이터 구조 (`/me` 엔드포인트)

`/정보` 명령어에서 호출하는 `https://lixcampus.com/api/v1/lix-bot/me` 엔드포인트의 응답 객체(JSON) 구조입니다. 최상위에 `bot` 객체가 있으며 내부에 다음과 같은 속성을 가집니다.

* **`id`** (`String`): 봇에 부여된 고유 식별값입니다. (예: `6379545c026a7d65`)
* **`name`** (`String`): 봇의 이름입니다. (예: `testbot`)
* **`description`** (`String`): 봇에 대한 간략한 설명입니다. (예: `자동 데이터 읽어오기.`)
* **`webhookUrl`** (`String`): 봇이 이벤트를 수신할 웹훅 URL입니다. 비어있을 수 있습니다.
* **`scopes`** (`Array`): 봇이 부여받은 접근 권한 목록입니다. (예: `["posts:read", "moderation:check"]`)
* **`enabled`** (`Boolean`): 봇의 현재 활성화 상태입니다. (`true`일 경우 활성화됨)
* **`installationApprovalRequired`** (`Boolean`): 봇 설치 시 관리자의 승인이 필요한지 여부입니다.
* **`tokenIssuedAt`** (`String`): 봇의 API 토큰이 발급된 날짜와 시간입니다. (ISO 8601 형식)
* **`createdAt`** (`String`): 봇이 처음 생성된 날짜와 시간입니다. (ISO 8601 형식)
* **`updatedAt`** (`String`): 봇의 정보가 마지막으로 업데이트된 날짜와 시간입니다. (ISO 8601 형식)
